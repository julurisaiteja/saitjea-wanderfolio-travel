# Wanderfolio

Curated tours for travelers who write their own stories.

**Style:** Postcard Collage travel  
**Diamond batch:** 4 (#35)  

## Run locally

```bash
npm i
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
npm run build
npm start
```

## Features

- Homepage film (autoplay muted loop + poster fallback)
- AI assistant with niche Q&A
- Offers / coupon `WANDER200`
- Reviews, deep catalog (search/filter/sort), PDP specs & FAQ
- Cart → Stripe-style checkout → success
- Niche desk: `/atlas` (Atlas)
- Locations, journal, account/loyalty teaser, newsletter
- Soft motion + reduced-motion respect

## Stack

Next.js 14 App Router · React 18 · Tailwind CSS · TypeScript
